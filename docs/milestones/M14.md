# M14 — Spatial Reactor — PLAN

**Strategic epic:** Epic B — Spatial Reactor.  
**Status:** PLANNED — prerequisite M13 closed.

## Goal

Evolve the reference plant from an aggregated visual core toward a deterministic quasi-spatial 2D educational reactor model with multiple zones/equivalent channel groups, explicit rod mapping and selectable local evidence layers, without implying licensing-grade full-channel neutron transport.

## Fidelity boundary

M14 is a reduced-order spatial model. Documentation and UI must say when values are zone/group equivalents rather than individual physical-channel solutions.

## M14.1 — Quasi-spatial contract and limits

Freeze zone/group identity, mapping rules, conservation/aggregation contracts, deterministic ordering and explicit unsupported claims before changing the reference plant.

## M14.2 — Multi-zone/equivalent-channel-group reference core

Introduce multiple deterministic 2D zones/equivalent channel groups in the reference composition, with canonical IDs and aggregate consistency against whole-core power, flow, inventory and thermal ownership.

## M14.3 — Multiple rods / rod groups and zone mapping

Represent multiple rods or rod groups with explicit spatial influence/mapping. Commands remain typed and canonical; zone mapping is definition-owned rather than UI-authored.

## M14.4 — Local/quasi-spatial feedback and evidence

Where physically justified by the reduced-order model, expose deterministic local/group evidence for power, flow, void, temperature and xenon, with clearly defined coupling to aggregate/global state.

## M14.5 — 2D core map and selectable layers

Add educational layers for:

- power;
- flow;
- void;
- temperature;
- xenon;
- rod position/influence.

Layer rendering consumes canonical snapshots and adds no physics.

## M14.6 — Local drill-down and trends

Allow zone/group selection, local trends and contextual diagnostics while retaining the reduced-order fidelity disclaimer.

## M14.7 — Spatial closure gate

Require deterministic same-seed/replay/checkpoint equivalence, aggregate conservation consistency, bounded performance cost and manual review that the UI does not imply unsupported channel-by-channel neutron transport.

Local damage overlays remain disabled until M15 introduces a physical damage owner.
