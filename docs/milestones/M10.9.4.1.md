## F.2 — Conservative Main-Steam Header Relief — CANDIDATE

F.2 adds one optional pressure-actuated external relief path to the current-v2 main-steam network:

```text
id                         header-relief
source node                header
receiver boundary          atmospheric-relief-receiver
receiver pressure          0.101325 MPa
set pressure               6.500000 MPa
full-lift pressure         6.700000 MPa
full-open throat area      1,600 mm²
```

The relief:

- reads only committed header state;
- derives stateless pressure lift;
- limits ideal-vapor effective area by committed vapor availability;
- invokes the validated F.1 capacity solver;
- emits one source-node mass/internal-energy removal and matching signed external exchange;
- is combined before the existing single plant-network integration;
- is enabled only in the two current-v2 sustained profiles;
- remains absent from legacy/default definitions.

No turbine bypass, condenser receiver inventory, manual authority, valve travel/hysteresis, alarm/protection function, two-phase critical-flow correlation, enthalpy migration or HMI change is included.

See ADR 0116, `M10_9_4_1_F2_MAIN_STEAM_RELIEF.md` and `M10_9_4_1_F2_VALIDATION_CHECKLIST.md`.
