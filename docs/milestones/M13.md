# M13 — Control-Room Experience — PLAN

**Strategic epic:** Epic C — Control-Room Experience.  
**Status:** PLANNED — prerequisite M12 closed.

## Goal

Make the simulator feel and operate more like a coherent industrial control room while preserving the existing subsystem/workspace architecture, canonical command boundaries and strict separation between presentation and plant physics.

## Fixed principles

- keep area/subsystem workspaces; no giant all-controls page;
- Avalonia/IndustrialControls remain presentation adapters only;
- multi-monitor/multi-computer operation remains deferred;
- presets change presentation only;
- mimic layout changes never alter plant topology;
- Instructor/Fault authority may invoke only mechanisms actually modeled at that milestone.

## M13.1 — Industrial presentation boundary and visual identity

Integrate appropriate `archistico/IndustrialControls` controls where they improve readability/operability and strengthen the retro-industrial visual system without duplicating simulation logic in UI controls.

## M13.2 — Maintained operator-handle semantics

Model maintained selector/handle position separately from effective equipment state where the real control semantics require it. Preserve momentary pushbutton, spring-return, breaker CLOSE/TRIP and reset distinctions rather than applying one global handle model.

Handle/selector state must remain deterministic and replay-visible.

## M13.3 — First-class mimic viewport

Add zoom around pointer/focus, pan, fit/reset, stable selection and subsystem drill-down while preserving canonical topology and readable alarms/measurements.

## M13.4 — Versioned persistent mimic layout

Add explicit `EDIT LAYOUT`, drag, optional alignment aids, `LOCK LAYOUT` and `RESET TO DEFAULT`. Persist overrides as `EquipmentId → visual position`, versioned against stable canonical IDs. Missing IDs are ignored; new equipment uses canonical defaults.

## M13.5 — Workspace presets

Add presentation-only presets such as STARTUP, SYNCHRONIZATION, NORMAL GENERATION, REACTOR TRANSIENT, TURBINE TRIP, ELECTRICAL EVENT and LOCA RESPONSE. Presets may change workspace, viewport, layers/trends and panel expansion; they may not move plant controls or clear trips.

## M13.6 — Real operating procedures

Add procedures over canonical commands, permissives and evidence: alignment, steam admission, synchronization, reset/recovery and emergency-response sequences. Procedures guide/evaluate; they never directly write physical outcomes.

## M13.7 — Instructor / Fault mode

Add a visually unmistakable Instructor/Fault mode using the deterministic fault framework and only the degradation/damage mechanisms available at that time. Instructor-only actions must never masquerade as normal operator controls.

## M13.8 — Integrated UX closure

Validate keyboard-only use, minimum window, all subsystem workspaces, mimic viewport/layout persistence, presets, procedures, Instructor/Fault distinction, replay/session restoration and visual-state determinism.
